# Provenance

Derived from the original Eden Forge editorial website by Mohamad Hassan, copyright 2026, MIT licensed. This release extracts the visual technique and a reusable demonstration, not the research runtime.

The inspected source renderer has SHA-256 `163c309c9b1d07d6380972ca124f90661bec24bbe6a54b897055a3ecc6f59376`. It draws the accepted original chip-stack style. The reusable version adds configurable layers, a frozen elapsed-time clock, document visibility handling, motion-preference updates cleanup on unmount, and a final annotation pass for unobscured labels. The two functions describing projection remain equivalent for the default five-layer layout.

All demo copy is original. System fonts and procedural Canvas geometry are used; no external fonts, stock media, Anatomy assets, private experiment records, credentials, source-hosting identity or provider protocol histories are included. The repository uses the MIT licence in `LICENSE`.

Local validation is documented by the focused check command and browser captures under ignored `runs/verification/`. Validation demonstrates UI behaviour; it does not establish chip functionality or lab capability.
