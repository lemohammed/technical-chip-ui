Technical Chip UI 1.0.0 extracts the original Eden Forge editorial design into a reusable MIT-licensed skill.

Includes skill instructions, a complete responsive HTML/CSS/Canvas starter, configurable chip layers, projection and design documentation, and focused local checks. Play/Pause, keyboard selection, reduced motion, offscreen suspension and continuous resume are included.

No runtime dependencies, external fonts or image assets are required. GitHub Actions are disabled.
